# Separate shared work from personal alerts

Stagecom derives the shared Work Queue from unresolved Theater and Event state, presents watch-only Operational Exceptions separately, and treats Notifications as personal domain-event-derived alerts. Reading or dismissing a Notification never resolves shared work or changes the underlying condition, so every authorized person sees the same operational truth without losing personal control over attention.

Callsheet presents a person's own commitments separately from authorized
shared Work Queue decisions across their Theaters. Theater Operations presents
the Theater Operator's resolvable decisions, then Operational Exceptions for
conditions that merit monitoring or action by another relationship. Queue
priority follows domain urgency and eligibility; there are no manually created
tasks or personal priority overrides.
